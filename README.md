# Plant Support Net: Mesh and Roll Size Worksheet

For climbing and spreading crops grown through a wide-mesh net.

## Steps
1. Measure the bed length and width, and decide if the net stands upright or lies flat over the bed.
2. Pick the mesh opening to suit the crop's stems and fruit.
3. Choose the roll width and length so that cuts and joins are few. Add an allowance for fixing at the ends.
4. Note the number of layers if the crop grows tall.
